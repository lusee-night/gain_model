# gain_model
Gain and Noise modelling

How to run:

Download data.zip from https://drive.google.com/drive/u/1/folders/1_WuITEiGzKsa6BNC7wwkJwWZnA4vpjsN

Unzip to ~/gain_model/data

All scripts (with the exception of those in ~/gain_model/scripts/old_scripts) assume the location of ~/gain_model/data


# Noise Model Pipeline

This script performs PCA/SVD-based modeling of the LuSEE-Night receiver noise
using grouped CPT science-session HDF5 data.

The outputs generated by this script are the required inputs for:

```bash
get_corrected_noise.py
```

outputs.zip in https://drive.google.com/drive/u/1/folders/1_WuITEiGzKsa6BNC7wwkJwWZnA4vpjsN will work if unzipped to ~/gain_model/outputs

# What the Script Produces

The script generates the noise-model outputs required by:

```bash
get_corrected_noise.py
```

Outputs are written under:

```text
~/gain_model/outputs/noise_svd_nmod4/
```

including:

```text
nmod4_1/
nmod4_2/
nmod4_3/
```

---

# Auto-Correlation Outputs (Products 0-3)

For products:

```text
0, 1, 2, 3
```

the final products used by `get_corrected_noise.py`
come from:

```text
gain_<GAIN>/svd_3/
```

These use:

- preamp-subtracted spectra
- low-frequency smoothing
- SVD stage 3 products
- fractional residual reconstruction

---

# Cross-Correlation Outputs (Products 4-15)

For products:

```text
4-15
```

the final products used by `get_corrected_noise.py`
come from:

```text
gain_<GAINPAIR>/svd_1/
```

These use:

- direct nV/sqrt(Hz) conversion
- SVD stage 1 products
- absolute residual reconstruction

---

# Exported Products

The script exports:

```text

pc_regression_alphas.csv
```

along with:

- diagnostic plots
- PDFs
